# Nairien Jahan Era - Personal Website

React + Vite + Tailwind CSS + Framer Motion. Neo-Brutalist pastel design, 15 sections.

## Run
    npm install
    npm run dev        # http://localhost:5173
    npm run build      # production build in /dist

## Customise
- All text, cars, goals, quotes, letter and social links: `src/data.js`
- Photo: put `nairien.jpg` inside `public/` (the "N" placeholder is shown until then)
- Colours: `tailwind.config.js`

## Deploy
Push to GitHub and import into Vercel or Netlify (build: `npm run build`, output: `dist`).
